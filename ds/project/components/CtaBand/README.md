# CtaBand

Ferme une page sur une action : titre, phrase, un ou deux boutons.

Dégradé `green-900 → green-600`, rayon `radius-lg`, padding `space-10` / `space-9`.
Sur ce fond, la seule variante de contour autorisée est `outline` (contour blanc) :
`outline-green` y devient illisible.

Propriétés : `title`, `text`, `actions` (liste de propriétés de `Button`).

- Un seul bandeau par page, tout en bas.
- Deux actions au maximum, la seconde en `outline`.
- Le titre est une question ou une invitation, jamais un slogan.
