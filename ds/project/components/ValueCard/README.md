# ValueCard

Porte une valeur de marque : pictogramme centré, titre, une phrase.

Fond `green-50`, rayon `radius-md` — plus discret qu'une `Card`, parce qu'une valeur se
lit, ne se clique pas. Pas d'effet de survol.

Propriétés : `icon`, `title`, `text`.

- Les quatre valeurs d'AgriWin Togo sont fiabilité, qualité, proximité, ouverture.
  N'en inventez pas d'autres pour remplir une grille.
- Une phrase, pas deux. Si la valeur demande un paragraphe, c'est une section à part.
