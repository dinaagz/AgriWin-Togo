# Brand

Bloc d'identité : symbole, nom, signature.

Le nom est en Poppins 700 19px `green-900`, la signature « Votre partenaire agricole ! »
en Playfair Display italique 12px `ink-500`, avec l'espace insécable avant le point
d'exclamation. Sur fond sombre, `onDark` passe le nom en blanc et la signature en blanc à 60 %.

Propriétés : `logo` (URL du SVG, à prendre dans le groupe d'assets Logos), `onDark`.

- Le symbole conserve son ratio de 0,64 ; il ne se déforme ni ne se recadre.
- La signature accompagne le nom dans l'en-tête et le pied de page ; elle disparaît sur
  les usages très réduits (favicon, avatar), où seul le monogramme est utilisé.
- Le nom s'écrit toujours « AgriWin Togo » : deux majuscules internes, un espace avant Togo.
