# Logos

Les six fichiers du logo AgriWin Togo, en SVG vectoriel. Le symbole est un plant de sisal à six feuilles — deux hampes centrales presque verticales, deux feuilles latérales montantes et deux feuilles extérieures retombantes — avec une chèvre au trait à leur pied : la culture et l'élevage, les deux métiers de l'entreprise, dans un seul signe.
Il est vectorisé depuis le logo d'origine, non redessiné.

| Fichier | Quand l'utiliser |
| --- | --- |
| `agriwin-logo-principal.svg` | Verrouillage vertical. Format carré ou portrait : affiche, couverture de document, publication sociale. |
| `agriwin-logo-horizontal.svg` | Verrouillage horizontal. En-tête de site, papeterie, bandeau, signature d'e-mail. |
| `agriwin-icone.svg` | Symbole seul, sans texte. Quand le nom est déjà écrit à côté. |
| `agriwin-logo-mono.svg` | Une seule encre, `green-950`. Tampon, gravure, fax, impression une couleur. |
| `agriwin-logo-inverse.svg` | Sur aplat `green-900` ou sur photo foncée. Le fond vert fait partie du fichier. |
| `agriwin-monogramme.svg` | Carré `green-900` à coins arrondis. Favicon, avatar de réseau social, tuile d'application. |

Chaque fichier porte ses propres couleurs : ce ne sont pas des marques à une encre et elles
n'héritent pas de la couleur du texte. Pour changer d'encre, changez de fichier.

Zone de protection : la hauteur de la hampe centrale divisée par quatre, sur les quatre côtés.
Taille minimale : 28 mm de large à l'impression, 120 px à l'écran pour la version
horizontale ; en dessous, passez au monogramme.

À ne pas faire : déformer le symbole, le recadrer, le recolorer, l'incliner, ajouter une
ombre portée, le poser sur une photo chargée sans aplat de protection, ou remplacer la
signature par une autre accroche.
