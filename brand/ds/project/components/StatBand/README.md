# StatBand

Bande de chiffres clés sur le dégradé `green-900 → green-700`.

Le chiffre est en `gold-500` Poppins 34px, le libellé en blanc à 85 %. La paire
`gold-500` sur `green-900` tient 3.69:1 : elle ne passe qu'en grand texte, ce que la
taille 34px garantit. N'utilisez jamais cette paire pour un libellé.

Propriétés : `items` — une liste de `{ value, label }`. Trois ou quatre entrées.

- Des chiffres vérifiables : une date de création, un nombre de variétés, une zone
  couverte. Pas de « 100 % de clients satisfaits » sans source.
- Quatre colonnes au maximum ; au-delà, le libellé passe sur trois lignes.
