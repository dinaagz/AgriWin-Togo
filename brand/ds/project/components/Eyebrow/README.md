# Eyebrow

Annonce le thème d'une section, au-dessus de son titre.

Texte en capitales, `green-900` sur `green-100` — 6.83:1. La combinaison d'origine du site
(`green-700` sur `green-100`) ne donnait que 4.45:1 : elle est corrigée ici.
Sur aplat vert, passez `onDark` — le fond devient un blanc à 15 % et le texte `white`.

Propriétés : `label`, `icon`, `onDark`.

- Deux à quatre mots. Un surtitre qui fait une phrase est un chapô, pas un surtitre.
- Un seul par section, toujours suivi d'un `SectionHead`.
- N'en faites jamais un lien ni un bouton : la pastille ressemble à un bouton, elle ne
  doit pas se comporter comme tel.
