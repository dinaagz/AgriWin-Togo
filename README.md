# AgriWin Togo — identité de marque, design system et brand book

Identité de marque, design system web et brand book A3 pour **AgriWin Togo**
(Kégué, Togo) : conseil agricole, formation, plants tropicaux, écoulement de
produits et accompagnement en élevage.

Ce dépôt réunit :

- le **logo** vectorisé en six variantes SVG/PNG (`logo/`) ;
- un **design system** publié comme artefact claude.ai (`ds/project/`,
  URL dans `out/artifact-url.txt`) ;
- un **brand book A3 paysage** en PDF et en PowerPoint éditable (`out/`).

Le détail du projet — règles de travail, chaîne de génération, portes de
contrôle, historique — est documenté dans [`CLAUDE.md`](./CLAUDE.md). Tout le
contenu du dépôt est en français.
